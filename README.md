# Pure Bootstrap 5 Layout Practice

A fully responsive, single-page UI layout built exclusively with HTML5 and Bootstrap 5. This project serves as a practical implementation of core Bootstrap components and utility classes without relying on any custom CSS or external JavaScript logic.

## 🎯 Project Objective

The main goal of this repository is to demonstrate proficiency in combining various Bootstrap structures. It focuses strictly on Bootstrap's native classes to achieve a modern, responsive design, ensuring that components like Grids, Flexbox, and Alerts work together seamlessly across all screen sizes.

## 🛠️ Built With

*   **HTML5** (Semantic structuring)
*   **Bootstrap 5** (CSS Framework)
*   **Bootstrap Icons** (Typography and iconography)

## 💡 Key Bootstrap Concepts Applied

This project successfully integrates the following 15 Bootstrap concepts:

*   **Alerts (`alert`, `alert-dismissible`):** Implemented a perfectly aligned, dismissible top notification bar.
*   **Grid System (`row`, `col-*`):** Created a responsive speaker lineup that adapts from 1 column on mobile to 4 columns on desktop.
*   **Flexbox (`d-flex`, `justify-content-*`, `align-items-*`):** Used extensively in the sticky header and component alignment.
*   **Position Utilities (`position-sticky`, `position-relative`, `position-absolute`):** Applied for the sticky navigation bar and overlaying the date badge on the hero image.
*   **Tables (`table-striped`, `table-hover`):** Built a structured, easily readable event schedule.
*   **Display Utilities (`d-none`, `d-md-block`):** Managed responsive visibility to hide unnecessary elements on smaller screens.
*   **Spacing Utilities (`m-*`, `p-*`):** Handled margins and padding efficiently without custom CSS.
*   **Typography & Colors:** Utilized Bootstrap's native text (`fs-*`, `fw-*`) and background/border color classes.
*   **Images & Borders:** Applied `img-fluid`, `rounded-circle`, and border utilities for clean visual components.

## 📱 Responsive Behavior

*   **Mobile (< 768px):** Stacked grid layouts, hidden center navigation (to save space), and streamlined typography.
*   **Tablet (≥ 768px):** 2-column grid structures and visible navigation menus.
*   **Desktop (≥ 992px):** Full 4-column layouts and expanded UI elements.
